# Sonic Arcade (Project Arcade)

A retro launcher for the classic Sonic games on Windows 10/11, made by Emaad Quadri.

## Install

1. Open **[Releases](../../releases/latest)** and download **Sonic Arcade Setup.exe**.
2. Double-click it. If Windows says "Windows protected your PC", click **More info → Run anyway**.
3. Sonic Arcade appears on your desktop and in the Start menu, and keeps itself up to date.

**No games are included.** You need your own game files (.bin).

To uninstall: Windows **Settings → Apps → Sonic Arcade → Uninstall**.
